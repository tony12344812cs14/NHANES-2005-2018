閘門題由資料推得（step6_gates.py -> gates.csv）：
  purity   = 有答 F 的人裡，閘門 G 落在 S 的比例（≈1 表示 F 只問 G∈S 的人）
  coverage = G∈S 的人裡，有答 F 的比例（≈1 表示 G∈S 的人都會被問 F）

處理原則（使用者 10/28 同意）：
  1. 「沒問 = 答案可以確定」才轉換（例如複選題沒勾 = 沒選，從沒抽菸的人每天抽 0 支）
  2. 重要題組把閘門題 + 追問題做成衍生變數
  3. 其他追問題不用，只留閘門題
  4. 先不加「是否缺失」指示變數（跳答規則跨 cycle 有變，會變成 cycle 訊號）

選項：
  (a) 不用這些題；
  (b) 保留，加一類「不適用（年齡 / 性別不符）」，樹模型可直接處理；
  (c) 限縮族群（例如只分析 20-59 歲）。

編碼：
   原值 / 邏輯確定的 0 ：有答，或由閘門題確定（例：從不抽菸 -> 每天 0 支、複選題沒勾 -> 0）

   NaN                ：真的缺失（有資格被問但沒答、拒答、不知道），之後插補
建模時：樹模型直接用 -1；線性模型類別變數 one-hot（不適用自成一欄），
        數值變數拆成「數值（-1 改 0）」+「不適用指標」。
不適用指標完全由年齡 / 性別決定，不帶新資訊、也不是 cycle 訊號；
實作前要逐 cycle 確認年齡 / 性別限制沒有改過，若某 cycle 不同，該題另外處理。
