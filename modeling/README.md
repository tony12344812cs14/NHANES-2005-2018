# 建模進度

預測目標：憂鬱（PHQ-9 ≥ 10），資料為 `outputs/features/features_2005_2018.csv.gz`
（33,498 人 × 317 個特徵，2005–06 到 2017–18 共 7 個 cycle，盛行率 8.9%）。

## 計畫

| 步驟 | 內容 | 狀態 |
|---|---|---|
| 0 | 用特徵猜 cycle，當作診斷工具（找 bug、找方法改變），不是要壓低的目標 | 完成 |
| 1 | 切資料：leave-one-cycle-out（主要）、2005–14 訓練 / 2015–18 測試、隨機分層 5-fold（樂觀上限） | LOCO 完成；時間切分、隨機 5-fold 未做 |
| 2 | 模型：logistic regression（elastic net，基準）、XGBoost（主模型）；再比較 kNN、CatBoost、TabM（step 2）；人口學特徵的參考模型之後再加 | 5 個模型完成；人口學參考模型未做 |
| 3 | 指標：**AUROC（主指標，10/29 使用者確認）**；輔助 AUPRC、Brier 與校準、固定閾值的敏感度 / 特異度；加權與不加權各報一次 | 已確認 |
| 4 | 解釋：SHAP，並檢查有沒有可疑的洩漏特徵 | 未開始 |

所有前處理（插補、標準化、特徵選擇）都只在訓練集上 fit。

## 指標怎麼算

每個測試 cycle 各算一次，程式在 `step1_loco.py` 的 `metrics()`（step 2 共用）。

| 指標 | 意思 | 算法 |
|---|---|---|
| **AUROC**（主指標） | 隨機挑一個憂鬱者、一個非憂鬱者，模型給憂鬱者較高分數的機率；0.5 = 亂猜、1 = 完美。只看排序，不受機率尺度與盛行率影響 | `roc_auc_score(y, p)` |
| 加權 AUROC | 同上，但把樣本推回美國人口：每一對人的重要性 = 兩人調查權重相乘 | `roc_auc_score(y, p, sample_weight=WTMEC2YR)` |
| AUPRC | precision–recall 曲線下面積，著重模型抓陽性的能力；基準值等於盛行率（約 0.09），不是 0.5 | `average_precision_score(y, p)` |
| Brier | 預測機率與實際 0/1 的均方差，越低越好；同時反映區辨力與校準 | `brier_score_loss(y, p)` |

彙總方式：

- **主要數字**：7 個測試 cycle 各自的指標取平均 ± 標準差，每個 cycle 權重相同。標準差是 cycle 之間的變異，不是抽樣誤差。
- **合併 AUROC**：把 7 折的預測接在一起算一次 AUROC，人數多的 cycle 影響較大；不同折的模型機率尺度不完全一致，所以只當輔助。

加權 AUROC 的說明：

- NHANES 刻意多抽某些族群（西語裔、非裔、2011 起的亞裔、老年人、低收入者），並有拒訪差異，樣本比例和美國人口不同。
  CDC 給每個人權重 `WTMEC2YR`，代表「這個人代表多少美國人」：多抽的族群權重小，少抽的權重大。
- 一般 AUROC 反映「這份樣本」裡的表現；加權 AUROC 估計「用在全美成年人身上」的表現。兩者接近，表示模型不是只在被多抽的族群表現好。
- 用 `WTMEC2YR`（MEC 檢查權重）是因為 PHQ-9 在 MEC 施測。權重只用在評估，訓練不用。
- 只算點估計；嚴謹的信賴區間需要考慮抽樣設計（`SDMVPSU`、`SDMVSTRA`），目前沒做。

注意事項：

- 訓練時用了 class weight（elastic net `balanced`、XGBoost `scale_pos_weight`、CatBoost `Balanced`、TabM loss 的 `pos_weight`），預測機率會被往上推，Brier 偏高；kNN 沒用 class weight，所以 Brier 不能跨模型直接比。
- 模型都還沒校準；校準、固定閾值的敏感度 / 特異度之後再補。

## 紀錄

### 10/29 Step 0 第 1 次：cycle 還分得很清楚

`step0_cycle_check.py`：7 類 XGBoost 只用特徵猜 cycle，5-fold。

- 準確率 **0.768**（隨機猜 0.156）；各 cycle one-vs-rest AUROC 0.91–0.997，2005–06、2015–16、2017–18 最容易分辨。
- 單一特徵最能分辨 cycle 的，以及處理方式：

| 來源 | 細節 | 處理 |
|---|---|---|
| 程式錯誤 | `RHD280`（子宮切除）2005–06 補值時「否」同時是 0 和 2，跳 1.5 SD | 已修正 |
| 睡眠 `sleep_hours_z`（單特徵 AUC 0.74） | z 分數只對齊平均，兩時期的數值集合不同 | 恢復原始時數 `sleep_hours`（見第 2 次） |
| 2005–06 肌酸酐 | CDC 強烈建議校正 | 套 CDC 公式 0.978x − 0.016 |
| 2017–18 生化（LDH 跳 0.9 SD 等） | 換成 Roche Cobas 6000，CDC 有換算公式 | 套 CDC 反向公式（12 項）；球蛋白、滲透壓重算 |
| 血球 RDW、WBC、HCT、MCH、MCHC | 2012 年換儀器，CDC 沒給公式 | 維持原始量測值（見第 2 次） |
| 2017–18 鈉、氯、鉀、碳酸氫鹽、滲透壓 | CDC「不建議調整」 | 維持原始量測值（見第 2 次） |
| 人口變化（2011 起亞裔加抽、收入隨通膨上升） | 真實差異 | 不處理，留給 leave-one-cycle-out 反映 |

校正後：肌酸酐、GGT、ALT、AST、尿酸的 cycle 差距都在 0.1 SD 以內；LDH 從 0.9 降到 0.29 SD。
細節與 CDC 原文出處見 `docs/skip_pattern_plan.txt` 第十一節。

### 10/29 Step 0 第 2 次：準確率反而升到 0.969，撤回只為壓低它的處理

當時多做了兩件事：睡眠改成各時期內五分位、血球與電解質在各 cycle 內 z 分數。結果準確率從 0.768 升到
0.969：鈉這類整數量測做了 z 分數後，同一個 140 在每個 cycle 變成不同的數，模型看數值就能認出 cycle。

決定（使用者）：轉換睡眠是在破壞特徵本身，而把「猜 cycle 準確率」壓到隨機沒有意義，cycle 之間本來就有
真實差異。因此：

- 睡眠恢復為原始時數 `sleep_hours`；血球與電解質維持原始量測值。
- 保留 CDC 公布的校正公式（2005–06 肌酸酐、2017–18 生化）與 `RHD280` 的 bug 修正。
- Step 0 之後只當診斷工具。跨 cycle 的差異會影響多少預測，交給 leave-one-cycle-out 的結果回答。

### 10/29 Step 1：基準線（elastic net）與主模型（XGBoost），leave-one-cycle-out

`step1_loco.py`。每個 cycle 輪流當測試集，超參數用訓練的 6 個 cycle 內層 LOCO、以平均 AUROC 挑。
主指標彙總：7 個測試 cycle 各自 AUROC 的平均（每個 cycle 權重相同），另附合併預測的 AUROC。

- 網格：elastic net C ∈ {0.01, 0.1, 1} × l1_ratio ∈ {0, 0.5, 1}；XGBoost max_depth ∈ {3, 5} ×
  min_child_weight ∈ {1, 10}，learning rate 0.05、樹數由 early stopping 決定。
- 計時時發現特徵字典把 68 個飲食兩天平均標成類別（改名成 `DR_*` 後找不到原本的數值範圍），
  one-hot 出 10,991 欄；已修正為連續，設計矩陣 803 欄。
- 單折試算（測試 2005–06）：XGBoost AUROC 0.890、elastic net 0.888，僅供估時，不是正式結果。

結果（7 個測試 cycle 的平均 ± 標準差；完整表在 `outputs/modeling/step1/report.txt`）：

| 模型 | AUROC（主） | 加權 AUROC | AUPRC | Brier | 合併 AUROC |
|---|---|---|---|---|---|
| elastic net | **0.874 ± 0.011** | 0.877 ± 0.018 | 0.481 ± 0.036 | 0.137 ± 0.007 | 0.872 |
| XGBoost | 0.871 ± 0.010 | 0.875 ± 0.016 | 0.481 ± 0.032 | 0.129 ± 0.005 | 0.870 |

各測試 cycle 的 AUROC（elastic net / XGBoost）：2005–06 0.894 / 0.888、2007–08 0.877 / 0.874、
2009–10 0.866 / 0.865、2011–12 0.871 / 0.866、2013–14 0.869 / 0.864、2015–16 0.878 / 0.879、
2017–18 0.860 / 0.861。

- 兩個模型差距 0.003，小於 cycle 之間的差異（0.86–0.89）；elastic net 在 5 個 cycle 略高，XGBoost 在 2015–16、2017–18 略高。
- 選到的參數每折一致：elastic net 都是 C = 0.01、l1_ratio = 0.5（強正則化）；XGBoost 都是 max_depth = 3、樹 225–284 棵。
  樹模型偏好淺樹、線性模型就追平，表示這組特徵的訊號以單變數、近似加成的效果為主。
- 最新的 2017–18 最低（0.860），最早的 2005–06 最高（0.894，但該 cycle 盛行率只有 6.2%）。
- Brier 受 class weight 影響（機率被往上推），兩者都還沒校準，Brier 只能拿來相對比較。
- 每折時間：elastic net 約 14 分鐘（saga），XGBoost 約 2 分鐘。

### 10/29 Step 2：kNN、CatBoost、TabM（排在 step 1 之後，自動接著跑）

`step2_more_models.py`，同樣的 LOCO 切法與指標。使用者指定這三個模型、實作細節由我決定：

| 模型 | 輸入 | 調參 | 目的 |
|---|---|---|---|
| kNN | 與 logistic regression 相同的設計矩陣（one-hot + 標準化） | k ∈ {50, 150, 400}，內層 LOCO | 非參數的距離方法對照 |
| CatBoost | 全部特徵；類別特徵用 CatBoost 原生類別編碼，-1 與缺失各自一類 | depth ∈ {4, 6}，內層 LOCO；樹數 early stopping | 比較不同樹模型與類別處理 |
| TabM | 全部特徵；數值 quantile-normal + 不適用指標，類別為整數編碼 | 不做網格，用套件預設（k=32、3×512、dropout 0.1），early stopping 用訓練資料的 15% | 評估深度學習是否再改善 |

- TabM 不做網格：深度模型調參成本高，原作者也建議預設值；早停集與測試 cycle 無關。
- TabM 只用完全沒有程式在跑的 GPU（啟動 TabM 當下才檢查），否則用 CPU。
- 新裝套件：`tabm==0.0.3`、`rtdl_num_embeddings==0.0.12`（`--no-deps`，沒有動到 torch）。
- 快速測試（只跑 2005–06 一折、最小網格，非正式結果）：kNN 0.766、CatBoost 0.890、TabM（3 個 epoch）0.889。

結果（7 個測試 cycle 的平均 ± 標準差，與 step 1 合併；完整表在 `outputs/modeling/step2/report.txt`）：

| 模型 | AUROC（主） | 加權 AUROC | AUPRC | Brier |
|---|---|---|---|---|
| elastic net | **0.874 ± 0.011** | 0.877 | 0.481 | 0.137 |
| CatBoost | 0.873 ± 0.010 | 0.877 | 0.482 | 0.133 |
| TabM | 0.872 ± 0.011 | 0.875 | 0.481 | 0.141 |
| XGBoost | 0.871 ± 0.010 | 0.875 | 0.481 | 0.129 |
| kNN | 0.802 ± 0.010 | 0.802 | 0.348 | 0.075 |

各測試 cycle 的 AUROC（elastic net / CatBoost / TabM / XGBoost / kNN）：

| 測試 cycle | elastic net | CatBoost | TabM | XGBoost | kNN |
|---|---|---|---|---|---|
| 2005–06 | 0.894 | 0.890 | 0.889 | 0.888 | 0.792 |
| 2007–08 | 0.877 | 0.876 | 0.875 | 0.874 | 0.798 |
| 2009–10 | 0.866 | 0.866 | 0.859 | 0.865 | 0.792 |
| 2011–12 | 0.871 | 0.868 | 0.870 | 0.866 | 0.819 |
| 2013–14 | 0.869 | 0.868 | 0.866 | 0.864 | 0.808 |
| 2015–16 | 0.878 | 0.880 | 0.881 | 0.879 | 0.807 |
| 2017–18 | 0.860 | 0.860 | 0.861 | 0.861 | 0.795 |

- 除了 kNN，四個模型平均 AUROC 落在 0.871–0.874，差距 0.003，比 cycle 之間的差異（約 0.03）小一個數量級。
  換樹模型、換類別處理（CatBoost 原生編碼 vs XGBoost 直接吃代碼）、換深度學習都沒有帶來改善。
- CatBoost 比 XGBoost 高 0.002，7 個 cycle 中 5 個較高，差距在雜訊範圍內。depth 4 與 6 各被選中 3–4 次，樹 215–322 棵。
- TabM 用預設參數就追平樹模型，每折只要約 0.4 分鐘（GPU，18–23 個 epoch 早停）；Brier 的 cycle 間變異最大（± 0.025），機率尺度較不穩定。
- kNN 明顯落後（0.802）。每折都選到網格上限 k = 400，代表 k 再加大可能還會進步一點，但與其他模型差 0.07，不太可能追上；
  kNN 沒有 class weight，所以 Brier 較低，不能和其他模型直接比。
- 結論：在這組 317 個特徵上，模型選擇幾乎不影響 AUROC，訊號以近似加成的單變數效果為主。
  可解釋性與簡單性以 elastic net 最佳；後續解釋（SHAP）可用 XGBoost 或 CatBoost 對照 elastic net 係數。
